**What's new in our entry** (say this explicitly in the post):
1. It measures **small local open-weight models**, the kind people run inside offline agents, on **your own laptop with fixed seeds**.
2. **TabPFN scores a name offline**, from generation-time features only. It needs no network, and it can still flag a name a squatter has since registered.
3. **Leave-one-model-out**: does a ghost detector trained on two models catch the third model's ghosts?
4. **Natural experiment**: how many of the names the models invented **already exist** on PyPI, and who registered them, and when?
5. A **working guard** with an offline mode, plus responsible disclosure: we never publish unregistered names that attackers could claim.

## 6. Technical facts verified on Oct 28

**TabPFN**
- TabPFN-3.5, released Sep 15 2026. Only the **Base** and **Fast** weights are open; Plus and Thinking are API-only.
- `pip install tabpfn` (v9.0.0, Python ≥3.10, PyTorch ≥2.5).
- Weights license: non-commercial. Accept it at platform.priorlabs.ai/account/licenses, then set `TABPFN_TOKEN` and `TABPFN_NO_BROWSER=1`.
- The README says *"On CPU, only moderate datasets are feasible"*, with **5,000 samples as the CPU default limit**. Use `ignore_pretraining_limits=True` to go past it.
- Sources: https://docs.priorlabs.ai/models/accessing-model-weights · https://github.com/PriorLabs/TabPFN

**Ollama (Gemma 4)**
- Tags: `gemma4:e2b`, `gemma4:e4b` (`:latest`), `12b`, `26b`, `31b`.
- Structured outputs work through `format=<json schema>`.
- Source: https://ollama.com/library/gemma4/tags

**Ultramarine (Paper Instruments)**
- OpenAI SDK base URL `https://api.paperinstruments.com/v1`; model `ultramarine-1-flash`; env `PAPERINSTRUMENTS_API_KEY`.
- **Prepaid** pricing: $0.15 per 1M input tokens, $0.50 per 1M output tokens. Responses don't include a cost field, so compute it from `usage`. `GET /v1/pricing` returns current rates.
- Source: https://docs.paperinstruments.com/docs

**PyPI and package data** (all tested live on Oct 28)
- `https://pypi.org/pypi/<name>/json` returns 200 with the full release history and `upload_time` per file, or **404 if the package doesn't exist**.
- Top 15k packages: `https://hugovk.dev/top-pypi-packages/top-pypi-packages-30-days.min.json`, 15,000 rows, last updated 2026-10-01. The old `hugovk.github.io` URL redirects to it.
- ecosyste.ms: `https://packages.ecosyste.ms/api/v1/registries/pypi.org/packages/<name>` returns downloads, dependents and `repo_metadata` (archived, pushed_at, scorecard).

**pypistats**
- `https://pypistats.org/api/packages/<name>/recent`. **Check the response shape before relying on it.**
