## 1. Spracklen et al., "We Have a Package for You!" (USENIX Security 2025)

- **Source:** https://arxiv.org/abs/2406.10279 (abstract) and https://arxiv.org/html/2406.10279 (v3 full text)
- **Authors:** Joseph Spracklen, Raveen Wijewickrama, A H M Nazmus Sakib, Anindya Maiti, Bimal Viswanath, Murtuza Jadliwala.
- **Venue (abstract):** "To appear in the 2025 USENIX Security Symposium."
- **Verbatim from the abstract:**
  - "we generate 576,000 code samples in two programming languages that we analyze for package hallucinations."
  - "the average percentage of hallucinated packages is at least 5.2% for commercial models and 21.7% for open-source models"
  - "including a staggering 205,474 unique examples of hallucinated package names"
- **From the v3 full text.** These are paraphrased by the fetch tool, not quoted verbatim. Re-check against the PDF before quoting exact figures.
  - 16 models, about 2.23 million package recommendations, about 19.7% hallucinated overall.
  - Python 15.8% vs JavaScript 21.3%.
  - Lowest rate: GPT-4 Turbo, 3.59%. Best open-source: DeepSeek 1.3B, 13.63%.
  - Re-running the same prompt 10 times, about 43% of hallucinated packages appeared in all 10 runs and about 39% never reappeared.
  - About 81% of unique hallucinated names were generated by only one model.
  - Name similarity: of 76,489 hallucinated packages, 13.4% were within Levenshtein distance 1–2 of a real package, 37.9% at 3–5 and 48.6% at 6 or more.
  - About 8.7% of hallucinated Python names were valid npm packages.
  - Hallucination rates rise with temperature.
  - Self-detection ("Is [package name] a valid Python package?"): three of four models tested (GPT-4 Turbo, GPT-3.5, DeepSeek) were above 75% accuracy. CodeLlama labelled most packages valid.
- The repeat statistics (43% / 39% / 58% repeated more than once) are also quoted verbatim by Socket (§3).

## 5. Blog-ready credit paragraph (≈170 words)

> This isn't a new ghost story. Spracklen et al. generated 576,000 code samples and found hallucinated packages averaged at least 5.2% for commercial models and 21.7% for open-source ones, with 205,474 unique invented names ([USENIX Security 2025](https://arxiv.org/abs/2406.10279)). Bar Lanyado at Lasso Security registered one recurring ghost, `huggingface-cli`, as an empty package and watched it collect more than 30,000 authentic downloads in three months ([Lasso](https://www.lasso.security/blog/ai-package-hallucinations)). Seth Larson gave the attack its name: slopsquatting ([Socket](https://socket.dev/blog/slopsquatting-how-ai-hallucinations-are-fueling-a-new-class-of-supply-chain-attacks)). My numbers are smaller and not directly comparable: three small local models, 200 Python tasks, two samples each, at temperature 0.7. Still, 15.1% of 1,410 install suggestions were ghosts (8.1% to 20.9% by model). 40 of 162 ghost names (24.7%) came back at least twice, though only 10 (6.2%) from two or more models. Unlike the self-detection results in that paper, my gemma4 said "doesn't exist" to 143 of 271 real packages.

## 6. What's new here (one sentence)

> Prior work measured package hallucinations and asked registries after the fact. Phantom Packages adds an offline TabPFN detector that scores a name from generation-time features alone, tested by prompt, leave-one-model-out and on unseen names. It also ships a keyed-anonymised ghost registry and a working guard: a CLI, a Claude Code hook and a GitHub Action.
